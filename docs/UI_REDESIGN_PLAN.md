# 我的钥匙 · Moonlight Glass 原生改造计划

> 产品来源：`rponeawa/QinlinOpen`（MIT）；本仓库为个人 Fork。  
> 本文跟踪改造的真实进度。设计稿是原型，不是已实现的 Android 功能。

## 已确认目标

- 名称：「我的钥匙」；视觉：Apple Wallet 卡片堆叠，月光银 Liquid Glass。
- 品牌色 `#71859A`，辅助 `#D6E2EC`，浅背景 `#EAF1F7`，深背景 `#253348`。
- 4～10 把同小区钥匙；卡片前景轻点开门，其他卡片先选中；保留服务端原名称。
- 启动默认显示上一次**成功开门**的钥匙；开门请求中拒绝重复请求。
- 真实成功响应后才展示解锁动画；失败/超时只提供**手动重试**，不自动重试。
- 保留现有短信登录、`QinlinApi`、`SecureStore`、Android Keystore 和每个桌面组件独立绑定钥匙的安全语义。
- 新旧 App 同时安装，独立数据区；新版需要单独登录，不从旧版提取会话。
- 原生 120Hz 是**目标**，不是当前测试结论。需要真机性能分析。

## 动效验收规范

参考 `emilkowalski/skills` 中的 `apple-design`：

1. 按压立即产生可见反馈，提交动作在正常触摸抬起时触发。
2. 手指移动与卡片位移 1:1 对应；滑动阈值避免误触开门。
3. 松手速度传递给物理弹簧；动画能随时中断或反向，不跳帧回位。
4. 进入/退出沿一致路径，抽屉有明确触发位置；越界拖动用逐渐增大的阻力。
5. 半透明材质层次服务于信息可读性；不是整屏模糊、循环特效。
6. 成功时同步视觉和轻振动；失败信息可读；减少动态效果时退化为静态或淡入淡出。
7. Android 使用 Jetpack Compose 原生动画；120Hz 设备需采集真实掉帧和主线程耗时。

### 阶段 02：Codex PR #2 第一轮审查修复（2026-10-17）
